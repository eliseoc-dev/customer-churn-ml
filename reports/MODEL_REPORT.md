# Customer Churn Model Report

## Objective

Predict whether a customer is likely to churn using behavioral, billing and account information.

## Models Evaluated

- Logistic Regression
- Random Forest

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## Selected Model

The final model is automatically selected based on F1 score.

## Important Features

Feature importance is extracted from the selected model to understand which variables contribute most to churn predictions.

## Business Use Case

The model can help identify high-risk customers so retention teams can prioritize:

- Discounts
- Customer support
- Contract upgrades
- Personalized offers
- Engagement campaigns

## Limitations

This project uses synthetic data and should not be used for real business decisions without validation using real customer data.
