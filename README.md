# Customer Churn Prediction

Machine learning project focused on predicting customer churn using classification models.

## Technologies

- Python
- Pandas
- NumPy
- scikit-learn
- Matplotlib
- Jupyter Notebook
- pytest
- Git
- GitHub

## Project Goals

The project demonstrates:

- Data preprocessing
- Feature engineering
- Classification
- Model training
- Model evaluation
- Precision, recall and F1-score
- Confusion matrices
- Feature importance
- Model persistence
- Reproducible ML workflows
